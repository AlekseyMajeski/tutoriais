Argox O4-250 Pro

A O4-250 Pro é uma impressora desktop de etiquetas de 203 dpi, até 7 ips, com USB, RS-232 e Ethernet integrados. A página oficial oferece diretamente o Argox Windows Printer Driver 12.5.0 e prevê Wi-Fi/Bluetooth como opcionais.

Instalação no Windows 11

1

Baixe o driver

Execute Argox_12.5.0.exe como administrador.

2

Selecione O4-250 Pro

Escolha o modelo exato no assistente.

3

Configure a conexão

USB é o caminho mais simples para o primeiro teste. Para Ethernet, descubra o IP e crie uma porta TCP/IP.

4

Calibre a mídia

Defina largura, altura, tipo de sensor e ribbon antes da impressão de produção.

Rede e wireless: Ethernet 10/100 faz parte das interfaces padrão. Wi-Fi e Bluetooth são opcionais; confirme o hardware instalado antes de tentar configurar conexão sem fio.
Qual driver usar no Windows 11?

Use o Argox Windows Printer Driver 12.5.0 listado na página oficial da O4-250 Pro.

Rede fica offline

Confira o IP e use endereço fixo ou reserva DHCP.

Etiqueta pula

Revise tamanho/tipo de mídia e calibre os sensores antes de alterar o layout.
