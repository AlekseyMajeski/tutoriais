Argox OS-2140

A OS-2140 é uma impressora de etiquetas da linha desktop Argox. A página oficial preservada pelo fabricante oferece o Argox Windows Printer Driver 12.5.0, descrito pela própria Argox como compatível com todas as impressoras Argox.

Instalação no Windows 11

1

Baixe o driver oficial

Execute Argox_12.5.0.exe como administrador.

2

Selecione OS-2140

Escolha o modelo exato no assistente.

3

Conecte a impressora

Faça o primeiro teste pela interface disponível na sua unidade e confirme a porta criada pelo Windows.

4

Configure a etiqueta

Informe largura, altura e método de impressão corretos antes da página de teste.

Se pular etiquetas: revise o tipo de mídia e faça a calibração do sensor antes de alterar o layout do sistema. Em transferência térmica, confira também o ribbon.
A OS-2140 é antiga. O driver ainda é oficial?

Sim. A Argox mantém a página do modelo e disponibiliza o driver Windows atual declarado para todas as impressoras Argox.

O Windows reconhece, mas não imprime

Confira a fila, a porta selecionada e faça um teste pelo próprio Windows antes de revisar o sistema emissor.

A etiqueta sai fora de posição

Confirme tamanho, tipo de mídia e calibração do sensor.
