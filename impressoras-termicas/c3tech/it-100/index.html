Instalação por USB no Windows

O procedimento principal é baixar, extrair, instalar e testar.

1

Confirme IT-100

Veja a etiqueta da impressora e confirme o modelo antes de instalar.

2

Baixe o pacote oficial

Use o botão acima para baixar DRIVES IT-100.rar.

3

Extraia o arquivo RAR

Use um descompactador compatível com RAR e extraia o conteúdo para uma pasta local.

4

Execute o instalador do Windows

Abra o instalador correspondente ao Windows, de preferência como administrador, e avance. Conecte a IT-100 por USB quando solicitado ou quando for necessário para a detecção.

5

Faça uma página de teste

Abra Impressoras e scanners no Windows, selecione a IT-100 e use Propriedades da impressora → Imprimir página de teste.

Instalação por Ethernet / IP

A IT-100 possui LAN integrada. Antes de criar a porta de rede no Windows, descubra o endereço IP atual da impressora.

1

Conecte o cabo LAN

Ligue a impressora ao roteador ou switch e mantenha o computador na mesma rede.

2

Descubra o IP

Use o procedimento de status/autoteste ou o utilitário de rede fornecido no pacote do fabricante, quando disponível para sua versão do driver.

3

Evite IP mudando

Em PDV, configure um endereço estável ou uma reserva DHCP para que o Windows e o sistema continuem apontando para o mesmo equipamento.

4

Teste o endereço

Use ping ENDEREÇO-IP no Prompt de Comando para verificar comunicação básica.

5

Configure a porta TCP/IP

No driver do Windows, associe a impressora ao IP correto e finalize com uma página de teste.

Teste rápido antes de mexer no driver

Se a impressora não imprime, primeiro confirme se o hardware está funcionando.

Faça o autoteste conforme o procedimento indicado no manual/pacote da IT-100. Se ela imprime e corta no autoteste, concentre a investigação no driver, cabo USB, IP, porta TCP/IP ou configuração do sistema.

Problemas comuns

Comece pelo sintoma.

O Windows não encontra a IT-100 por USB

Troque cabo e porta USB, evite hubs, reinicie a impressora e reinstale o pacote oficial.

A IT-100 de rede parou de imprimir

Confira se o IP mudou. Se mudou, atualize a porta TCP/IP no Windows e depois configure um endereço estável.

A página de teste funciona, mas o PDV não imprime

Se o Windows imprime, revise no sistema qual impressora ou IP foi selecionado e se o envio direto ESC/POS está apontando para a porta correta.

Preciso instalar tinta ou ribbon?

Não. A IT-100 usa impressão térmica direta e papel térmico de 80 mm.

Posso usar bobina de 58 mm?

A ficha técnica oficial da IT-100 especifica papel de 80 mm. Não trate a IT-100 como modelo 58/80 sem confirmação do fabricante.
