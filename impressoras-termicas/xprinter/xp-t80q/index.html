Como instalar no Windows

Faça primeiro o spooler e o teste do Windows; configure o PDV somente depois.

1

Baixe e execute o instalador

Abra o pacote oficial como administrador e avance pelo assistente.

2

Conecte a interface correta

Para USB, conecte o cabo diretamente ao PC. Em rede, deixe a impressora e o computador na mesma rede durante a configuração inicial.

3

Selecione a porta

USB usa a porta criada pelo Windows. Ethernet deve usar uma Standard TCP/IP apontando para o IP da impressora.

4

Imprima uma página de teste

Confirme no Windows antes de cadastrar a impressora no sistema de vendas.

Problemas comuns

Separe driver, porta, rede e hardware antes de reinstalar.

Instala, mas não imprime

Confira se a fila está usando a porta da XP-T80Q real, e não uma USB antiga ou outro IP.

Rede fica offline

Teste o IP no navegador/ping e confirme se o endereço não mudou após reiniciar o roteador.

PDV não imprime

Primeiro faça a página de teste do Windows. Se ela sair, o próximo diagnóstico é a configuração do sistema/ESC-POS.

Perguntas rápidas

Toda XP-T80Q tem as mesmas portas?

Não. A fabricante lista configurações diferentes, incluindo USB e rede como opções comuns e variantes com Serial, Wi‑Fi ou Bluetooth.

Posso usar o driver de 80 mm da XPrinter?

Sim. A família 80Q aparece na lista de compatibilidade do pacote oficial atual de 80 mm.
