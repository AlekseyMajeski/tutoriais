Como instalar no Windows

O procedimento USB é o mais simples e deve ser testado antes do PDV.

1

Baixe o driver oficial

Execute o instalador como administrador.

2

Conecte a XP-58IIH por USB

Prefira uma porta USB direta no computador, evitando hubs na primeira instalação.

3

Selecione a porta criada

Se houver várias portas USB virtuais, desligue outras impressoras térmicas temporariamente para identificar a correta.

4

Imprima a página de teste

Valide pelo Windows antes de abrir o sistema de vendas.

Versão com Bluetooth

Esse passo vale apenas para a variante que realmente possui Bluetooth.

Emparelhe primeiro

Faça o pareamento no Windows e confirme se foi criada uma porta/serviço utilizável pelo driver.

Não confunda modelo com interface

XP-58IIH é o modelo; Bluetooth é uma opção de interface. Uma unidade USB simples não ganha Bluetooth com outro driver.

Problemas comuns

Na maioria dos casos, o problema está em porta USB, cabo ou fila errada.

Windows não reconhece

Troque a porta USB, teste outro cabo e abra o Gerenciador de Dispositivos antes de reinstalar.

Instalou, mas não imprime

Confira se o driver está associado à porta que aparece quando a XP-58IIH é conectada.

Impressão cortada

Confirme papel 58 mm e largura configurada no driver ou no sistema.

Perguntas rápidas

O driver XP-58IIH é exclusivo?

Não. A fabricante distribui um pacote compartilhado para vários modelos 58 mm, e a XP-58IIH aparece explicitamente na lista atual.

Toda XP-58IIH tem Bluetooth?

Não. A página oficial lista USB e USB + Bluetooth como configurações diferentes.
