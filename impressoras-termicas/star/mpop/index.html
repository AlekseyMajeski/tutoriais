USB-C, USB-B e Bluetooth

As interfaces mudam conforme a variante. Modelos CBi incluem Bluetooth; não aplique instruções de pareamento a uma unidade que não tenha essa interface.
mPOP não aparece no Windows

Confirme o código do modelo, reinstale Star Windows Software e valide cabo/porta antes de revisar o PDV.

Imprime, mas a gaveta não abre

Confirme a configuração de acionamento da gaveta no driver e no sistema usado para impressão.

Bluetooth não aparece

Verifique se a unidade é uma variante CBi; Bluetooth não está presente em todas as versões.
