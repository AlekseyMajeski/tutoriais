Instalação USB

1

Baixe o pacote correto

Entre no suporte oficial Elgin e selecione o material da L42 Pro Full para seu sistema.

2

Instale antes de integrar ao ERP

Conclua o instalador e conecte a impressora diretamente a uma porta USB do computador.

3

Configure o tamanho da etiqueta

Informe largura, altura, orientação e mídia de acordo com a etiqueta realmente carregada.

4

Calibre e teste

Faça a calibração do sensor conforme a mídia e imprima uma etiqueta de teste antes de configurar o sistema.

Ethernet / IP

1

Confirme a interface da sua unidade

Antes de configurar rede, confira fisicamente a porta Ethernet e a identificação da versão.

2

Descubra o IP

Use o utilitário/documentação fornecido pela Elgin ou consulte a tabela DHCP do roteador.

3

Use endereço estável

Para ERP e expedição, prefira reserva DHCP ou IP fixo para evitar que a fila perca a impressora.

Serial RS-232

Em integração Serial, os parâmetros precisam coincidir nos dois lados. Confirme porta COM, velocidade, bits de dados, paridade e stop bits no software e na configuração da impressora. Não copie parâmetros de outro modelo sem verificar a documentação da L42 Pro Full.

Linguagem da etiqueta

EPL / ZPL

Se o ERP ou marketplace gera comandos compatíveis com impressoras Zebra, a compatibilidade declarada com EPL/ZPL pode simplificar a integração. Ainda assim, valide tamanho, fontes, códigos de barras e posicionamento com uma etiqueta real.

PPLA / PPLB

São outras linguagens declaradas pela Elgin para o modelo. Se o sistema oferece seleção de emulação, use exatamente a linguagem configurada no layout de impressão.

Problemas comuns

A etiqueta pula uma posição ou sai fora do corte?

Revise tamanho da mídia e faça nova calibração do sensor. Confirme também se o layout do sistema usa a mesma altura configurada no driver.

Imprime texto estranho em vez da etiqueta?

Verifique se a linguagem enviada pelo sistema corresponde à emulação configurada: EPL, ZPL, PPLA ou PPLB.

USB aparece, mas o ERP não imprime

Primeiro teste pelo driver/sistema operacional. Se funcionar, revise a impressora selecionada no ERP, linguagem e tamanho da etiqueta.

Rede fica offline depois de algum tempo

Confira se o endereço IP mudou. Para uso fixo, configure reserva DHCP ou endereço estável.

Posso usar qualquer driver L42?

Não é recomendável. L42DT, L42 Pro e L42 Pro Full não devem ser tratados automaticamente como o mesmo hardware. Use o pacote indicado pela Elgin para sua variante.
