Instalação principal por USB

Para a maioria dos PCs, o objetivo é instalar o driver do Windows e testar.

1

Confirme a etiqueta

Confira se a impressora é i9/i9 Full. Se estiver escrito i9 Full 2, consulte a observação acima antes de prosseguir.

2

Baixe o driver v1.8.0

Use o botão de download direto desta página.

3

Extraia o ZIP

Extraia todos os arquivos para uma pasta local antes de executar o instalador.

4

Execute o instalador

Abra o instalador como administrador e avance. Para uma instalação USB comum, use as opções padrão e mantenha a impressora ligada quando o instalador solicitar a detecção.

5

Faça uma página de teste

No Windows, abra Impressoras e scanners → Elgin i9 → Propriedades da impressora e mande imprimir uma página de teste.

Configuração por Ethernet / IP

Use este caminho quando o cabo RJ45 estiver conectado à i9.

1

Conecte a i9 à rede

Ligue o cabo Ethernet ao roteador/switch e mantenha o computador na mesma rede.

2

Descubra o IP da impressora

Use o autoteste/status da interface ou os utilitários e procedimentos técnicos disponibilizados pela Elgin. O repositório oficial possui documentação específica para configuração de IP fixo da i9.

3

Prefira um IP estável

Em restaurantes e PDVs, evite que o endereço mude após reinicializações do roteador. Configure IP fixo ou uma reserva DHCP coerente com a rede local.

4

Teste a comunicação

No Prompt de Comando, use ping ENDEREÇO-IP. Se responder, o computador alcança aquele endereço.

5

Adicione a impressora pela porta TCP/IP

Use o driver da i9 e associe a impressão ao endereço IP configurado. Finalize com uma página de teste.

Importante: ping respondendo confirma comunicação IP básica, mas não garante que a porta de impressão ou o sistema de PDV estejam configurados corretamente.

Comunicação Serial

A i9 também suporta conexão Serial. No Windows 11 existe um pacote específico de Serial Virtual no repositório da Elgin.

Confirme a porta COM e os parâmetros exigidos pelo sistema. Se precisar de porta serial virtual no Windows 11, use o pacote disponibilizado acima. Em integrações diretas, baud rate, bits, paridade e controle de fluxo precisam coincidir com a configuração usada pelo software.

Autoteste e diagnóstico

Antes de reinstalar driver, confirme se a impressora consegue imprimir sozinha.

Execute o autoteste conforme o manual da sua revisão. Se o autoteste imprime e corta corretamente, concentre o diagnóstico em cabo, driver, porta COM, IP ou configuração do PDV. Se nem o autoteste funciona, investigue papel, tampa, fonte, cabeça térmica ou hardware.

Problemas comuns

Comece pelo sintoma.

O Windows não encontra a i9 USB

Troque o cabo e a porta USB, evite hubs, reinicie a impressora e reinstale o driver principal.

A i9 de rede parou depois de trocar o roteador

O IP pode ter mudado ou a nova rede pode usar outra faixa. Descubra o IP atual, configure um endereço estável e atualize a porta usada pelo Windows/PDV.

A página de teste funciona, mas o sistema não imprime

Se o Windows imprime, driver e porta estão funcionando. Revise no sistema qual impressora, IP ou modo de comunicação está selecionado.

Preciso instalar o Serial Virtual?

Não para uma instalação USB comum. Use esse pacote quando sua configuração realmente depender de uma COM virtual, especialmente no Windows 11.

Tenho uma i9 Full 2

A Elgin comercializa uma revisão chamada i9 Full 2. Não presuma automaticamente que todo firmware/utilitário da i9 original é idêntico. Confirme a identificação do equipamento e valide o pacote no suporte atual da Elgin.
