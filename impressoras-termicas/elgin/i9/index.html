Serial e Serial Virtual no Windows 11

Use somente quando seu sistema exigir porta COM.

Na comunicação serial, porta COM e parâmetros precisam coincidir com o software. O pacote Driver i9 Serial Virtual Windows 11 existe para cenários específicos de virtualização da comunicação; ele não substitui o driver principal em uma instalação USB comum.

Autoteste e diagnóstico

Execute o autoteste conforme a documentação da sua revisão. Se a impressora imprime e corta corretamente sem o computador, concentre o diagnóstico em driver, cabo, COM, IP ou configuração do PDV. Se nem o autoteste funciona, investigue papel, tampa, fonte, cabeça térmica ou hardware.

Problemas comuns da Elgin i9

Use o sintoma para escolher o próximo teste.

Windows não encontra a i9 USB

Teste outro cabo e outra porta USB, evite hubs, reinicie a impressora e reinstale o driver principal.

A i9 aparece offline

Em rede, confira se o IP mudou. Em USB, verifique cabo, porta e a fila selecionada.

A página de teste funciona, mas o PDV não imprime

Se o Windows imprime, revise no sistema a fila, IP, COM ou modo de comunicação escolhido.

Preciso do Serial Virtual no Windows 11?

Somente se a integração realmente exigir uma COM virtual. Para impressão USB comum, use o driver principal.
