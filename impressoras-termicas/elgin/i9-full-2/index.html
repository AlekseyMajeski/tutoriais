Elgin i9 Full 2

A i9 Full 2, identificada pelo part number 46I9F2CKD001, combina USB, Ethernet e Serial RS-232, impressão de até 300 mm/s e guilhotina automática. A Elgin mantém os pacotes técnicos desta família dentro da área i9 do repositório oficial.

Instalação USB no Windows

É o caminho mais simples para começar.

1

Baixe o driver v1.8.0

Use o download oficial acima e extraia o ZIP por completo.

2

Execute como administrador

Abra o instalador do pacote e selecione a i9.

3

Conecte o USB

Faça o primeiro teste diretamente no computador, sem hub USB.

4

Confirme a porta

Verifique se o driver ficou associado à porta correta no Windows.

5

Imprima uma página de teste

Abra Impressoras e scanners → Elgin i9 → Propriedades da impressora e teste.

Ethernet: configurar o IP

A versão Full 2 possui interface Ethernet.

1

2

3

Defina endereço estável

4

Configure a porta no Windows

Associe o driver ao IP correto e faça uma página de teste.

Serial RS-232 e COM virtual

São cenários diferentes.

🔗 Serial física RS-232

Se o computador possui porta serial e o sistema fala diretamente com COM, configure número da porta, baud rate e demais parâmetros exatamente iguais nos dois lados.

🪟 COM virtual no Windows 11

Se o software antigo exige COM, mas a impressora está via USB, instale o pacote “Driver i9 Serial Virtual Windows 11” e depois veja qual COM apareceu no Gerenciador de Dispositivos.

Problemas comuns

O driver aparece como i9, não “i9 Full 2”. Está errado?

Não necessariamente. A área técnica oficial da Elgin organiza os pacotes sob o nome i9. O part number Full 2 usa essa família de software.

USB não imprime

Teste outro cabo e porta, evite hubs, reinstale o driver v1.8.0 e confirme a porta associada à impressora.

Ethernet funcionava e ficou offline

Use o ELGIN Utility para conferir se o IP mudou. Corrija a porta no Windows e configure um endereço estável.

Preciso instalar Serial Virtual?

Não para impressão comum pelo spooler. Instale somente se o seu software exigir uma porta COM.

Página de teste funciona, mas o sistema não

Revise a impressora selecionada, a porta/IP e o modo ESC/POS do sistema. Se usa serial, confira baud rate e número COM.
