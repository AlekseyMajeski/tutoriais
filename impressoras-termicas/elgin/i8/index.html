Instalação no Windows por USB

É o caminho mais comum para começar.

1

Baixe o driver v7.1.7

Use o botão acima e extraia o ZIP para uma pasta local.

2

Execute o instalador

Abra como administrador e siga o assistente do driver.

3

Escolha a conexão USB

Deixe a i8 ligada e conecte o cabo USB quando necessário para a detecção.

4

Conclua e teste

Abra Impressoras e scanners no Windows, selecione a Elgin i8 e faça uma página de teste.

Emular porta COM

A comunidade técnica da Elgin mantém procedimento específico para usar a i8 por COM virtual. Use apenas quando o sistema de automação exigir uma porta serial, não para impressão comum pelo spooler.

Ethernet: localizar e configurar o IP

A i8 possui porta de rede integrada.

1

Conecte ao roteador ou switch

Ligue o cabo Ethernet e mantenha o computador na mesma rede.

2

Descubra o endereço

Use o autoteste/status de rede ou o utilitário da Elgin disponível na área técnica da i8.

3

Defina um IP estável

Em PDV, use endereço fixo ou reserva DHCP para evitar que o sistema perca a impressora depois de reiniciar o roteador.

4

Teste com ping

No Windows, use ping ENDEREÇO-IP para confirmar conectividade básica.

5

Associe a porta no driver/PDV

Configure a impressão para o IP correto e faça uma impressão de teste.

Serial / RS-232

Use apenas quando o software exigir comunicação serial.

Confirme a porta COM e os parâmetros configurados no sistema. Em envio direto ESC/POS, baud rate, bits, paridade e controle de fluxo precisam coincidir com a impressora.

Problemas comuns

O Windows não reconhece a i8 por USB

Teste outra porta e cabo USB, evite hubs e reinstale o driver v7.1.7.

A i8 de rede ficou offline

Confira se o IP mudou. Depois de corrigir a porta, reserve um endereço estável.

A página de teste funciona, mas o PDV não

Revise no sistema se a impressão está configurada por spooler, IP ou COM e se o destino corresponde à instalação real.

Posso usar o driver da i9?

Não como regra. A Elgin mantém pacotes específicos da i8; use o driver destinado a este modelo.

Existe driver para Mac?

A ficha técnica informa compatibilidade com Mac, mas não localizamos um binário Mac atual na pasta técnica oficial da i8. Confirme no suporte da Elgin para a versão exata do macOS.
