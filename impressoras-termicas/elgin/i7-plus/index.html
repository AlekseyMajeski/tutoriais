Instalação por USB no Windows

É o fluxo principal para quem só precisa deixar a impressora pronta para imprimir.

1

Baixe o driver Windows

Use o botão de download direto acima e salve o ZIP.

2

Extraia todos os arquivos

Não execute o instalador diretamente de dentro do ZIP.

3

Execute como administrador

Abra o instalador do pacote e avance pelas opções padrão.

4

Selecione a conexão

Para instalação USB, conecte a i7 Plus diretamente ao computador quando o instalador solicitar ou quando for necessária a detecção.

5

Faça uma página de teste

Abra Configurações → Impressoras e scanners → i7 Plus → Propriedades da impressora e mande imprimir uma página de teste.

Quando usar Serial Virtual COM?

Somente quando o sistema de automação trabalha diretamente com uma porta COM. Depois de instalar o pacote, confirme no Gerenciador de Dispositivos qual número COM foi criado e configure o mesmo número no software.

Ethernet: localizar e configurar o IP

A i7 Plus atual é comercializada pela Elgin com interface Ethernet.

1

Conecte o cabo de rede

Ligue a impressora ao roteador ou switch e mantenha o computador na mesma rede.

2

Abra o Elgin Utility

Use o utilitário i7 Plus/i8 para localizar ou configurar a impressora.

3

Descubra o IP atual

Se o endereço estiver em outra faixa ou tiver mudado via DHCP, ajuste antes de cadastrar a porta.

4

Use endereço estável

Em PDV, configure IP fixo ou uma reserva DHCP para evitar que a impressora mude de endereço após reiniciar o roteador.

5

Cadastre a porta e teste

No Windows, associe o driver ao endereço IP da impressora e faça uma página de teste. Um ping respondendo confirma comunicação IP básica, mas a impressão ainda depende da porta/configuração correta.

🐧 Linux

Use o pacote Linux específico do repositório Elgin. Extraia, leia a documentação incluída e adicione a impressora pelo mecanismo de impressão da distribuição. Em máquina de produção, teste antes de atualizar distribuição ou CUPS.

Problemas comuns

O Windows não encontra a i7 Plus por USB

Troque cabo e porta USB, evite hubs e reinstale o driver Windows. Faça o teste com a impressora conectada diretamente ao PC.

Instalei o Serial Virtual COM e não sei qual porta usar

Abra o Gerenciador de Dispositivos e veja em Portas (COM e LPT) qual COM foi criada. Configure exatamente essa porta no sistema.

A i7 Plus de rede parou depois de trocar o roteador

O IP pode ter mudado. Use o Utility para localizar a impressora, configure um endereço estável e atualize a porta do Windows/PDV.

A página de teste funciona, mas o sistema não imprime

Se o Windows imprime, concentre o diagnóstico na impressora selecionada pelo sistema, IP/porta e modo de comunicação utilizado pelo PDV.

Posso usar o driver da i8?

Não misture os drivers só porque o utilitário atende os dois modelos. Use o pacote de driver próprio da i7 Plus.
