Sweda SI-2500

A SI-2500 aparece no acervo técnico da Sweda com VCOM, bibliotecas Windows e Linux e exemplos de comunicação direta. O material atual do fabricante não expõe um spooler moderno separado; por isso este guia diferencia claramente driver/porta virtual de biblioteca de integração.

Fluxo de instalação

1

Identifique como o sistema imprime

Fila do Windows, porta COM ou biblioteca direta são caminhos diferentes.

2

Se precisar de COM, instale o VCOM

Extraia o pacote oficial e conclua a instalação.

3

Confirme a COM

Abra o Gerenciador de Dispositivos e anote o número criado.

4

Se o software usa DLL

Instale a arquitetura correta da biblioteca e configure o modelo/porta dentro do aplicativo.

5

Faça teste isolado

Teste comunicação antes de integrar ao PDV.

VCOM: use quando o aplicativo só trabalha com COM. Depois da instalação, o número da porta configurado no software precisa ser exatamente o mesmo exibido no Windows.

Problemas comuns

Instalei a DLL e não apareceu impressora no Windows

Isso é esperado em integração direta: DLL não cria necessariamente uma fila de impressão. Verifique como seu sistema se comunica.

COM muda de número

Evite trocar a porta USB física e, se possível, fixe a COM no Gerenciador de Dispositivos.

Windows 11

Trate os pacotes como legados. Faça teste funcional completo antes de produção.
