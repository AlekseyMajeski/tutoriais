Instalar no Windows

1

Baixe e extraia o ZIP

Use o pacote oficial acima e extraia todos os arquivos.

2

Execute o instalador

Abra o instalador do driver e avance pelo assistente.

3

Escolha USB ou COM/LPT

Para USB direto, selecione USB. Se seu sistema exigir porta COM, use o fluxo VCOM.

4

Reconecte o cabo

Após finalizar, mantenha a impressora ligada e reconecte o USB.

5

Teste no Windows

Confirme a fila “Sweda printer” e imprima uma página de teste.

Serial e USB virtualizando COM

Quando usar VCOM: apenas se o sistema de PDV exige uma porta COM. O manual oficial mostra que, no Windows 10, o dispositivo pode aparecer como “Dispositivo Serial USB (COM X)”. Confirme o número no Gerenciador de Dispositivos e configure o mesmo no software.

Autoteste

Procedimento: com papel instalado, desligue a impressora, mantenha FEED pressionado e ligue. O autoteste imprime modelo, versão e configuração das chaves DIP.

Problemas comuns

O autoteste imprime, mas o Windows não

Revise cabo, driver e porta. Se o autoteste funciona, o mecanismo de impressão está operacional.

USB aparece como dispositivo serial

Isso pode ser normal no modo VCOM. Confira a COM criada e use a mesma configuração no PDV.

Windows 11

O acervo oficial declara até Windows 10. Em Windows 11, trate o pacote como legado e valide página de teste e estabilidade antes de colocar em produção.

Impressão fraca

Limpe a cabeça térmica conforme o manual e use papel adequado. Evite densidade excessiva porque reduz a vida útil da cabeça.
