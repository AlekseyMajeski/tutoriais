Instalação

1

Baixe o driver correto

Windows ou Linux conforme o computador.

2

Escolha a interface

A SI-600 já possui USB, Serial e Ethernet integradas.

3

Configure o tipo de mídia

Defina cupom, etiqueta com liner ou linerless conforme o uso.

4

Faça um teste

Valide impressão, avanço e corte antes de configurar o PDV.

Ethernet/IP pelo navegador

1

Conecte o cabo de rede

Ligue a SI-600 à mesma rede do computador.

2

Pressione Status

O manual orienta um toque no botão junto à Ethernet para imprimir o endereço IP.

3

Abra o IP no navegador

A interface web permite DHCP, IP, máscara e gateway.

4

Use endereço estável

Em PDV, fixe o IP ou crie reserva DHCP.

Problemas comuns

Não imprime ou imprime desconfigurada

Confira papel, tipo de mídia, driver e parâmetros. O manual também traz procedimento de reset para restaurar ajustes.

Ethernet não comunica

Imprima o status da rede, confira o IP e abra-o no navegador. Valide cabo e LEDs de link.

Linerless trava ou corta mal

Use mídia compatível e configuração específica. A velocidade e a vida útil declaradas para linerless são diferentes das do cupom comum.
