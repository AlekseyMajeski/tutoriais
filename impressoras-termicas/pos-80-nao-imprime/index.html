POS-80 não imprime

O objetivo é descobrir em qual camada a falha está: impressora, conexão, Windows/driver ou sistema de PDV.

Teste em camadas
autoteste → conexão → Windows → PDV

Checklist rápido

1

Faça o autoteste

Se a impressora não imprime sozinha, investigue papel, tampa, fonte, cabeça e hardware antes de mexer no Windows.

2

Confirme o modelo real

POS-80 é um nome genérico. Veja etiqueta, autoteste e VID/PID para garantir que o driver corresponde ao equipamento.

3

Teste a conexão

USB: troque cabo/porta. Ethernet: confira IP e ping. Serial: confirme COM e parâmetros.

4

Faça página de teste

No Windows, abra as propriedades da fila e imprima uma página de teste.

5

Confira a porta da fila

Uma fila pode existir e apontar para USB, COM ou IP errado. Corrija a porta antes de reinstalar tudo.

6

Só então revise o PDV

Se o Windows imprime, revise impressora selecionada, modo RAW/ESC-POS, IP/porta e largura de papel no sistema.

Sintomas comuns

Fila fica “Erro - Imprimindo”

Limpe a fila, reinicie o serviço de spooler e confirme se a porta ainda existe. Se o problema voltar, verifique driver e conexão.

Ethernet funcionava e parou

O IP pode ter mudado. Descubra o endereço atual e configure um IP estável ou reserva DHCP.

Página de teste funciona, mas cupom não

O problema tende a estar no PDV, layout, porta lógica ou modo de envio. Evite trocar driver que já está funcionando no Windows.

Imprime texto estranho

Confirme driver, linguagem ESC/POS, code page e se o sistema está mandando dados RAW para um dispositivo compatível.
