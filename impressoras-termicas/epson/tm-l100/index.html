Instalação

1

Baixe e extraia o ZIP

Use o APD 6.12PD acima e extraia o conteúdo antes de executar o instalador.

2

Confirme a interface

USB e Ethernet são comuns na linha; opções adicionais dependem da configuração da unidade.

3

Instale o driver

Execute o instalador e selecione a TM-L100 e a porta correspondente.

4

Configure a mídia e teste

Ajuste dimensões/sensor da etiqueta liner-free e faça uma impressão de teste antes do PDV.

Ethernet / IP

Para uso em rede: descubra o IP pela ferramenta/configuração Epson, teste a comunicação e prefira reserva DHCP ou IP estável no ambiente do PDV.

Problemas comuns

A etiqueta não para na posição correta

Revise a mídia selecionada, dimensões e configuração de sensor. Etiquetas liner-free exigem ajuste correto do material.

A impressora de rede fica offline

Confirme se o endereço IP mudou e se a porta do Windows/PDV aponta para o IP atual.

O APD instala, mas não imprime

Faça primeiro uma página de teste no Windows. Se ela falhar, revise porta/interface antes de mexer no sistema de vendas.
