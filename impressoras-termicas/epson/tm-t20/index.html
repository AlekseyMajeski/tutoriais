Instalação principal por USB

Na maioria dos computadores, o processo é simplesmente baixar, extrair, instalar e testar.

1

Confirme que é TM-T20

Veja a etiqueta. Se houver RJ45 e você pretende usar rede, vá para Rede / IP.

2

Baixe o APD

Use o botão de download direto acima e salve APD_513_T20.zip.

3

Extraia e execute

Extraia o ZIP para uma pasta e abra o instalador. Se possível, use Executar como administrador.

4

Avance com as opções padrão

Aceite os termos e siga em Avançar/Next. Quando o instalador pedir, deixe a TM-T20 ligada e conectada por USB.

5

Imprima uma página de teste

No Windows, abra Impressoras e scanners → EPSON TM-T20 → Propriedades da impressora e faça o teste.

Opção avançada: Printer Registration / cadastro manual

O APD permite cadastrar manualmente modelo e porta. Isso não precisa ser o caminho principal. Use quando a impressora não for criada automaticamente, houver várias unidades ou você precisar escolher uma porta específica.

Se a porta USB não aparecer, teste cabo/porta e, se necessário, instale o TMUSB oficial.

Versão de rede: localizar e configurar o IP

Use este caminho apenas se sua TM-T20 tiver interface Ethernet/RJ45.

1

Conecte o cabo de rede

Ligue a impressora ao roteador ou switch e aguarde a inicialização.

2

Descubra o IP

Faça o autoteste/status da interface ou use o EpsonNet Config para localizar equipamentos Epson na rede.

⬇️ Baixar EpsonNet Config 4.9.11

3

Defina um IP estável quando necessário

No EpsonNet Config, selecione a interface encontrada e ajuste o endereço para a rede do estabelecimento. Em PDV, manter um IP estável evita que o sistema perca a impressora após mudanças do DHCP.

4

Teste a comunicação

No Prompt de Comando, use ping 192.168.x.x substituindo pelo IP da impressora. Resposta indica que o computador alcança aquele endereço na rede.

Ping respondendo não garante sozinho que a porta de impressão esteja correta, mas elimina boa parte dos problemas básicos de rede.
5

Instale o APD e escolha a porta de rede

Instale o APD. Se for necessário selecionar a conexão manualmente, use a opção TCP/IP/rede e informe o IP configurado. Finalize imprimindo uma página de teste.

Se a sua versão for Serial

A instalação do driver continua usando o APD, mas a comunicação depende da porta COM e dos parâmetros da interface.

Confirme a porta COM usada no Windows e os parâmetros esperados pelo sistema que enviará a impressão. Se houver comunicação direta ESC/POS, velocidade, bits e controle de fluxo precisam coincidir entre o computador e a impressora.

Não copie configuração de USB ou Ethernet para uma unidade Serial. O hardware traseiro da impressora é o que determina o procedimento.

Autoteste sem computador

Ótimo para descobrir se o problema é da impressora ou do Windows/rede.

1

Desligue

Deixe bobina instalada e tampa fechada.

2

Segure FEED e ligue

Mantenha FEED pressionado ao ligar até o autoteste começar.

3

Interprete

Se o autoteste imprime corretamente, concentre o diagnóstico em driver, porta, IP ou software.

Bobina 80 mm ou 58 mm

A TM-T20 aceita as duas larguras previstas pelo fabricante.

80 mm

A especificação oficial usa papel de 79,5 ± 0,5 mm.

58 mm

Use a guia/espaçador apropriado e configure a largura. A especificação oficial usa papel de 57,5 ± 0,5 mm.

Problemas comuns

Comece pelo sintoma.

O Windows não encontra a TM-T20 USB

Teste outra porta USB e outro cabo, evite hubs e reinicie a impressora. Se a interface continuar sem aparecer, instale o TMUSB oficial e tente novamente.

A TM-T20 aparece offline

Confira se a porta configurada corresponde à conexão real. Em rede, confirme o IP e teste a comunicação. Em USB, confira se o dispositivo continua reconhecido pelo Windows.

O IP mudou e o sistema parou de imprimir

Descubra o endereço atual com o EpsonNet Config ou status da interface. Depois configure um IP estável e ajuste a porta usada pelo driver/sistema.

Sai papel em branco

Inverta a bobina e faça o autoteste. Papel térmico imprime somente no lado sensível ao calor.

A guilhotina não corta

Faça o autoteste. Se corta no autoteste, investigue driver ou comando do sistema. Se não corta nem no autoteste, verifique obstrução e mecanismo.

Posso usar driver da TM-T20II ou TM-T20X?

Evite. Use o pacote explicitamente destinado à TM-T20 original.

Configurações avançadas

Úteis para integração de PDV, mas não necessárias para a instalação normal.

ESC/POS, gaveta e caracteres

Sistemas que enviam comandos ESC/POS diretamente podem controlar corte, gaveta e página de código. A configuração precisa coincidir com o software que transmite os comandos.

OPOS, JavaPOS e SDK

São componentes de integração. Não baixe apenas para fazer uma impressão comum pelo Windows.
