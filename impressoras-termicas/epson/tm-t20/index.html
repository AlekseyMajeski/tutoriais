Epson TM-T20
Modelo original — não confundir com II, III ou X
Importante: TM-T20, TM-T20II, TM-T20III e TM-T20X são produtos diferentes. Confira a etiqueta antes de baixar.

Drivers por sistema operacional

Para modelos antigos, compatibilidade com sistemas atuais não deve ser presumida.

Windows

Advanced Printer Driver 5.13

Windows 11Windows 10ZIP

Driver principal da TM-T20 original para o spooler do Windows.

⬇️ Baixar APD 5.13

Arquivo oficial: APD_513_T20.zip.

macOS • legado

TM-T20 Printer Driver 1.2b

macOS 10.1410.1310.12OS X 10.11–10.5

A Epson ainda disponibiliza o pacote específico da TM-T20, mas o suporte oficial listado termina no macOS 10.14.

⬇️ Baixar driver Mac 1.2b

Arquivo: TM-T20_12b_AM.zip. Não trate macOS atual como compatível sem teste.

Linux • legado

TM/BA Series CUPS Driver

CUPSpacote legado

A documentação da própria Epson confirma que a TM-T20 foi fornecida com driver Linux CUPS. O driver Linux moderno 3.0.0, porém, já não lista a TM-T20 original.

Abrir Download Center da Epson

Preferimos não apontar um pacote Linux moderno incompatível só para oferecer um botão direto.

Instalação no Windows

Fluxo principal para a TM-T20.

1

Baixe o APD

Baixe e extraia APD_513_T20.zip.

2

Execute

Abra o instalador como administrador e avance.

3

Conecte

Para USB, ligue e conecte a impressora quando necessário. Para RJ45, veja Rede / IP.

4

Teste

Em Impressoras e scanners, abra as propriedades da EPSON TM-T20 e mande uma página de teste.

USB não reconhecida? TMUSB

Use o TMUSB oficial quando a interface USB não aparecer corretamente.

Printer Registration

Deixe o cadastro manual para casos em que a instalação simples não criar a impressora ou quando for necessário escolher uma porta específica.

🍎 macOS legado

  1. Baixe e extraia TM-T20_12b_AM.zip.
  2. Execute o instalador do driver.
  3. Abra Impressoras e Scanners.
  4. Adicione a TM-T20 e teste.
A Epson lista esse pacote somente até macOS 10.14.

🐧 Linux legado

A TM-T20 teve driver CUPS oficial e ele também aparece no Software & Documents Disc da Epson. Em uma máquina Linux atual, verifique compatibilidade da distribuição e do CUPS antes de alterar uma instalação que já funciona.

Versão Ethernet: localizar o IP

Somente para unidades com RJ45.

1

Conecte à rede

Ligue a TM-T20 ao roteador ou switch.

2

Descubra o IP

Use o status da interface ou o EpsonNet Config.

⬇️ EpsonNet Config para Windows

3

Configure um IP estável

Em PDV isso evita que o sistema perca a impressora quando o DHCP mudar o endereço.

4

Adicione pelo sistema

No Windows configure a porta TCP/IP no APD; em Mac/Linux use o mecanismo de impressão compatível com o driver disponível.

Autoteste

1

Desligue

Deixe papel e tampa fechada.

2

Segure FEED e ligue

Mantenha pressionado até a impressão começar.

3

Interprete

Se o autoteste funciona, investigue software, driver, cabo, porta ou IP.

Problemas comuns

Windows não encontra a USB

Teste outro cabo/porta, evite hub e instale o TMUSB se necessário.

Posso instalar no macOS 15 ou 26?

O driver específico 1.2b é listado pela Epson somente até macOS 10.14. Não considere suporte moderno garantido.

Posso usar o driver Linux 3.0.0 atual?

Não como recomendação oficial para esta geração: a lista atual desse pacote não inclui a TM-T20 original.

A página de teste funciona, mas meu sistema não

Revise no PDV a impressora, porta, IP e o modo de envio ESC/POS.
