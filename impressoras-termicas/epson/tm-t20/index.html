Epson TM-T20
Original — não confundir com II, III, X ou X-II
Resposta rápida: para Windows 11 ou Windows 10, o pacote principal desta TM-T20 original é o Advanced Printer Driver 5.13, arquivo APD_513_T20.zip, hospedado pela Epson.
Confira a etiqueta: TM-T20, TM-T20II, TM-T20III, TM-T20X e TM-T20X-II são produtos diferentes. Use este guia somente para a TM-T20 original.

Como instalar a Epson TM-T20 no Windows 11 ou 10

Faça primeiro uma instalação simples por USB e só depois configure o PDV.

1

Baixe o APD 5.13

Baixe e extraia APD_513_T20.zip.

2

Execute como administrador

Abra o instalador e selecione a TM-T20 original.

3

Conecte por USB

Use uma porta USB direta do computador e evite hub durante o primeiro teste.

4

Imprima uma página de teste

Abra Impressoras e scanners → EPSON TM-T20 → Propriedades da impressora e mande imprimir.

5

Configure o sistema

Somente depois da página de teste funcionar, selecione a mesma impressora no PDV/ERP.

USB não reconhecida? TMUSB

Quando a interface USB não aparecer corretamente, a Epson mantém o utilitário/driver TMUSB.

Problemas comuns da Epson TM-T20

Comece pelo sintoma e evite reinstalar tudo sem diagnóstico.

Windows 11 não encontra a TM-T20

Troque o cabo/porta USB, evite hub, reinicie a impressora e instale o APD 5.13. Se a USB não aparecer corretamente, teste o TMUSB.

Fica offline

Se for rede, confirme se o IP mudou. Se for USB, confira cabo, porta e fila selecionada no Windows.

A página de teste funciona, mas o sistema não imprime

Revise no PDV a impressora selecionada, porta/IP e o modo de envio esperado.

Imprime em branco ou muito fraco

Confirme se o papel é térmico e está com o lado sensível voltado para a cabeça. Se o autoteste também sair fraco, investigue papel/cabeça.

Posso usar o driver da TM-T20II ou TM-T20X?

Não como padrão. São modelos diferentes; use o pacote da sua geração.

Guia geral: impressora térmica não imprime · offline · USB não reconhece · imprime em branco.
