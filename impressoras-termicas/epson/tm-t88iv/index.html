Instalação

1

Confirme TM-T88IV

Veja a etiqueta e a placa de interface traseira.

2

Escolha o driver no suporte

Use somente pacote listado para a TM-T88IV.

3

Cadastre a interface

USB, COM ou TCP/IP conforme a placa instalada.

4

Página de teste

Valide pelo sistema operacional antes do PDV.

Rede: em unidades com placa Ethernet UB-E, descubra o IP da interface e use endereço estável. A documentação Epson mantém guias próprios para UB-E02/E03/E04 e módulos sem fio.

Problemas comuns

Driver de T88V funciona?

Não use como regra. São gerações diferentes; prefira o driver listado para TM-T88IV.

Rede offline

Confira a placa de rede, o IP atual e a porta TCP/IP configurada no computador.

Autoteste funciona, PC não

Revise driver, interface e porta; o autoteste funcional indica que o mecanismo básico está operacional.
