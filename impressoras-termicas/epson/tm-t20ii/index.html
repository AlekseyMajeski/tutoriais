Epson TM-T20II
Não confundir com TM-T20, TM-T20III ou TM-T20X
Modelo legado no macOS: o driver oficial específico para Mac é o v1.2b e a Epson o lista apenas até macOS 10.14. Para macOS moderno, não trate compatibilidade como garantida.

Drivers por sistema operacional

Baixe somente o pacote correspondente ao seu sistema.

Windows

Advanced Printer Driver 5.13

Windows 11Windows 10ZIP

Pacote principal da TM-T20II para impressão normal pelo Windows.

⬇️ Baixar APD 5.13

Arquivo oficial: APD_513_T20II.zip.

macOS • legado

Printer Driver for Mac 1.2b

macOS 10.1410.1310.12OS X 10.11–10.5

Driver oficial específico da TM-T20II. A própria Epson não lista macOS moderno nesse pacote.

⬇️ Baixar driver Mac 1.2b

Arquivo: tm-t20ii_macdrv_12b.zip. Não recomendamos assumir compatibilidade com macOS 15/26.

Linux • legado

TM/BA Series CUPS Driver

CUPSdistribuições antigas

A TM-T20II teve driver CUPS oficial, mas o pacote Linux 3.0.0 atual da Epson não inclui este modelo. Por isso não apontamos o pacote moderno como se fosse compatível.

Abrir suporte oficial Epson

Em Linux atual, valide distribuição, arquitetura e versão do CUPS antes de usar em produção.

Instalação no Windows

É o cenário mais comum.

1

Baixe o APD

Baixe APD_513_T20II.zip.

2

Extraia e execute

Extraia o ZIP e abra o instalador como administrador.

3

Avance normalmente

Aceite os termos e conecte a impressora por USB quando necessário.

4

Teste

Abra Impressoras e scanners, selecione EPSON TM-T20II e mande uma página de teste.

USB não aparece? TMUSB

Teste outro cabo e porta. Se a interface continuar sem aparecer, use o TMUSB v8.00d.

Printer Registration / cadastro manual

Use apenas quando a instalação automática não criar a impressora ou quando precisar escolher manualmente a porta.

🍎 Instalação no macOS legado

  1. Baixe e extraia tm-t20ii_macdrv_12b.zip.
  2. Abra a imagem/instalador do driver.
  3. Conclua a instalação.
  4. Em Impressoras e Scanners, adicione a EPSON TM-T20II.
  5. Teste impressão e guilhotina.
Se seu Mac roda uma versão mais nova que macOS 10.14, confirme compatibilidade antes de depender desta impressora.

🐧 Linux

O suporte Linux desta geração deve ser tratado como legado. A Epson historicamente forneceu o TM/BA Series CUPS Driver, mas o pacote moderno 3.0.0 já não lista a TM-T20II.

Em instalações existentes, preserve o pacote/PPD funcional e teste antes de atualizar distribuição ou CUPS.

USB, Serial e Ethernet

A interface varia conforme a versão vendida.

USB / Serial

No Windows, o APD continua sendo o driver principal. Em Serial, confirme porta COM e parâmetros da comunicação.

Ethernet / versões sem fio

Confirme a variante exata na etiqueta. Em rede, descubra o IP, mantenha um endereço estável e cadastre a impressora pelo sistema operacional ou pelo APD.

Autoteste

Teste rápido sem computador.

1

Desligue

Deixe papel e tampa fechada.

2

Segure FEED e ligue

Mantenha FEED pressionado até a impressão começar.

3

Interprete

Se imprime no autoteste, procure o problema no driver, porta, cabo, IP ou software.

Problemas comuns

Windows não encontra a USB

Troque cabo/porta, evite hub e, se necessário, instale o TMUSB oficial.

Meu Mac é novo. Posso usar o driver 1.2b?

A Epson lista oficialmente esse driver somente até macOS 10.14. Em macOS moderno, não considere compatibilidade garantida.

Posso usar o driver Linux 3.0.0 atual?

Não para a TM-T20II: a lista atual de modelos suportados desse pacote não inclui a T20II.

Página de teste funciona, mas o PDV não imprime

Revise no sistema qual impressora, porta, IP ou modo ESC/POS está selecionado.
