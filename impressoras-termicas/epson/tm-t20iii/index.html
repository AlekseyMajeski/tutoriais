Epson TM-T20III
Não confundir com TM-T20, TM-T20II ou TM-T20X
Confira a etiqueta: esta página é da TM-T20III. Modelos visualmente parecidos usam pacotes diferentes.

Drivers por sistema operacional

Não use o APD de Windows no Mac ou no Linux. Cada plataforma tem seu próprio pacote.

Windows • recomendado para PDV

Advanced Printer Driver 6.12PD

Windows 11Windows 10ZIP

Driver oficial específico da TM-T20III para impressão pelo spooler do Windows.

⬇️ Baixar APD 6.12

Arquivo: APD_612_T20III_WM.zip.

macOS

TM Series Printer Driver for Mac 3.0.1

macOS 15141312Apple Silicon / Intel

Driver CUPS comum da linha TM. A documentação oficial lista a TM-T20III entre os modelos suportados.

⬇️ Baixar driver para Mac

Se uma versão futura do macOS não aparecer como compatível, confirme no Download Center da Epson antes de instalar.

Linux • CUPS

Thermal Receipt Printer Driver 3.0.0

Ubuntu 22.04 LTSCentOS 7openSUSE Leap 15.4

Driver oficial CUPS distribuído pela Epson como código-fonte. Não é um instalador de duplo clique.

⬇️ Baixar driver Linux

Pacote: tmx-cups-src-ThermalReceipt-3.0.0.0.tar.gz.

Instalação no Windows

É o fluxo mais comum em restaurantes, lojas e PDVs.

1

Baixe o APD

Baixe e extraia APD_612_T20III_WM.zip.

2

Execute o instalador

Abra como administrador, aceite os termos e avance.

3

Conecte a impressora

Para USB, deixe a TM-T20III ligada e conecte quando solicitado. Para Ethernet, veja Rede / IP.

4

Teste

Em Impressoras e scanners, abra as propriedades da EPSON TM-T20III e mande uma página de teste.

Avançado: Printer Registration / escolha manual da porta

Use somente se a instalação simples não criar a impressora, houver várias unidades ou você precisar selecionar uma porta específica.

🍎 Como instalar no macOS

  1. Baixe e extraia o pacote do Mac.
  2. Abra o DMG/PKG do TM Series Printer Driver for Mac.
  3. Conclua a instalação.
  4. Abra Ajustes do Sistema → Impressoras e Scanners e adicione a TM-T20III.
  5. Faça uma impressão de teste e confira o corte.

🐧 Como instalar no Linux

  1. Baixe e extraia o pacote CUPS.
  2. Leia o README incluído, pois a Epson distribui essa versão como código-fonte.
  3. Compile/instale conforme a distribuição suportada.
  4. Adicione a impressora no CUPS por USB ou IP.
  5. Imprima uma página de teste.

Ethernet: localizar e configurar o IP

Use apenas se a sua variante tiver RJ45.

1

Conecte à rede

Ligue o cabo ao roteador/switch e a impressora.

2

Descubra o IP

Use o status/autoteste da interface ou o EpsonNet Config.

⬇️ EpsonNet Config para Windows

3

Use um endereço estável

Em PDV, mantenha um IP estável para evitar perda da impressora após mudança do DHCP.

4

Adicione pelo sistema operacional

No Windows use a porta TCP/IP do APD; no macOS ou Linux adicione a impressora de rede pelo mecanismo de impressão do sistema.

Autoteste

Ajuda a separar problema físico de problema de driver.

1

Desligue

Deixe papel instalado e tampa fechada.

2

Segure FEED e ligue

Mantenha FEED pressionado até o autoteste começar.

3

Interprete

Se o autoteste funciona, concentre o diagnóstico em driver, porta, IP ou software.

Problemas comuns

Comece pelo seu sistema e pelo sintoma.

Windows não encontra a impressora USB

Teste cabo e outra porta USB, evite hubs e execute novamente o APD.

Mac instalou o driver, mas a TM-T20III não aparece

Abra Impressoras e Scanners, adicione manualmente a impressora e confira se o driver Epson TM está selecionado. Em versões futuras do macOS, confirme compatibilidade na Epson.

Linux: baixei o arquivo e não há instalador

É esperado: a Epson distribui o driver Linux 3.0.0 como código-fonte para CUPS. Siga o README do pacote para compilar e instalar.

A impressora de rede aparece offline

Confira se o IP atual é o mesmo cadastrado no computador. Se mudou por DHCP, defina um endereço estável.

A página de teste funciona, mas o PDV não

O driver e a porta provavelmente estão corretos. Revise no sistema qual impressora, IP ou modo ESC/POS está selecionado.
