Epson TM-m50

A TM-m50 é uma impressora térmica compacta da linha mPOS da Epson. A documentação técnica oficial informa impressão de até 250 mm/s e suporte a múltiplas interfaces conforme a variante, incluindo USB, Ethernet/Wi‑Fi, Serial e Bluetooth.

Instalar no Windows

1

Confirme o modelo

Veja a etiqueta e confirme TM-m50. A TM-m50II usa outra geração de hardware.

2

No Windows, use o APD 6 da TM-m50

Abra a página oficial específica do APD 6, aceite a licença Epson e baixe o pacote oferecido atualmente para a TM-m50.

3

Escolha a interface

USB é o caminho mais simples. Para rede ou Serial, confirme primeiro qual interface existe fisicamente na sua unidade.

4

Teste pelo sistema

Imprima uma página de teste antes de configurar o PDV.

Ethernet / Wi‑Fi

Nem toda TM-m50 possui a mesma conectividade. Se sua unidade tiver rede, use WebConfig/EpsonNet para localizar ou definir o IP. Em PDV, prefira IP fixo ou reserva DHCP.

Problemas comuns

O computador não encontra a impressora

Confirme cabo, porta e interface instalada na unidade. Reinstale o driver Epson correspondente ao sistema operacional.

A impressora de rede ficou offline

Confira se o endereço IP mudou e se a porta TCP/IP cadastrada no Windows ainda aponta para o IP atual.

Página de teste funciona, mas o PDV não

Revise impressora selecionada, porta/IP e modo de comunicação do sistema. O teste do Windows funcionando indica que o problema provavelmente está na configuração do aplicativo.
