Instalar no Windows 11

Use o APD antes de configurar o aplicativo de vendas.

1

Confirme TM-m30III

Veja a etiqueta e não confunda com TM-m30 ou TM-m30II.

2

Baixe o APD 6.12

Execute APD_612_m30III_WM.exe como administrador.

3

Escolha a conexão

Para USB, conecte diretamente ao computador no primeiro teste. Para Ethernet, descubra o IP antes de criar a porta de rede.

4

Imprima página de teste

Valide a fila do Windows antes de apontar o PDV para a impressora.

Ethernet, Wi‑Fi e IP

1

Ethernet é integrada

Conecte a TM-m30III ao roteador/switch e mantenha o computador na mesma rede.

2

Descubra o IP

Use a folha de status, utilitário Epson ou Web Config.

3

Estabilize o endereço

Para uso em PDV, configure IP fixo ou reserva DHCP.

4

Wireless só quando existir

Wi‑Fi/Bluetooth depende da configuração/opção instalada. Não presuma que toda TM-m30III possui a interface sem fio.

Problemas comuns

Qual driver usar no Windows 11?

Use o Advanced Printer Driver 6 específico da TM-m30III Series. A Epson lista atualmente o arquivo APD_612_m30III_WM.exe.

USB-C carrega ou imprime?

A TM-m30III possui múltiplas portas USB e recursos de hub/sincronização. Para configuração do seu cenário, confira a função da porta no manual e faça primeiro a página de teste pelo caminho escolhido.

Rede ficou offline depois de reiniciar o roteador

Confira se o IP mudou. Atualize a porta TCP/IP e configure um endereço estável.

Não encontro Wi‑Fi ou Bluetooth

Essas interfaces são opcionais. Confirme a variante e o módulo presente na unidade.
