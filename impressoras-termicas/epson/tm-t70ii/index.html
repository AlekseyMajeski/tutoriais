Instalação rápida

1

Confirme a interface

USB é padrão; a segunda interface depende do código da unidade.

2

Baixe o driver oficial

Selecione seu Windows na página Epson.

3

Instale e escolha a porta

USB, Serial ou TCP/IP conforme o hardware.

4

Faça uma página de teste

Valide o Windows antes de configurar o PDV.

Ethernet/IP

Somente versões com Ethernet: descubra o IP, configure um endereço estável e associe o driver a uma porta TCP/IP. Se o IP mudar, a fila ficará offline.

Problemas comuns

Não encontro porta de rede

Confirme se sua unidade realmente possui interface Ethernet. A TM-T70II tem várias configurações.

USB funciona, mas o PDV não

Se a página de teste imprime, revise no sistema o nome da fila, porta e modo ESC/POS.

Impressora de rede offline

Confira se o IP atual coincide com o cadastrado na porta TCP/IP.
