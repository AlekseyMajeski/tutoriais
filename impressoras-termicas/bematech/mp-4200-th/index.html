Instalação principal por USB no Windows

Para a maioria dos técnicos, este é o caminho: baixar o spooler, executar, escolher MP-4200 TH, selecionar USB e testar.

1

Confirme o modelo

Veja a etiqueta e confirme MP-4200 TH. Se estiver escrito ADV ou HS, não siga este tutorial como se fosse a mesma revisão.

2

Baixe o Spooler 5.0.0.4

Baixe e extraia o pacote. Em Windows 64 bits, execute o instalador x64; em Windows 32 bits, use o x86.

3

Execute como administrador

Abra o instalador e mantenha marcada a opção de instalar o driver de spooler quando ela aparecer.

4

Escolha MP-4200 TH e USB

Selecione o modelo MP-4200 TH. Para a instalação comum, escolha USB e a porta detectada pelo instalador.

5

Imprima uma página de teste

Depois da instalação, abra Impressoras e scanners → MP-4200 TH → Propriedades da impressora e mande imprimir uma página de teste.

Avançado: tamanho de papel e cupons muito longos

Instalações antigas do spooler podem precisar de um formulário personalizado quando o cupom ultrapassa o tamanho padrão do Windows. Uma configuração historicamente usada para a MP-4200 TH é largura de 7,36 cm e altura de 95 cm, selecionando depois esse formulário nas propriedades da impressora. Só altere isso se o cupom estiver sendo cortado antes do final.

USB como porta COM virtual

Alguns sistemas de automação enviam comandos diretamente para uma porta COM em vez de imprimir pelo spooler.

Nesse cenário, instale o driver USB/COM, conecte a MP-4200 TH e veja no Gerenciador de Dispositivos → Portas (COM e LPT) qual COM foi criada.

Depois configure essa mesma porta no sistema. Em aplicações ESC/POS/Bematech, não misture RAW do spooler e COM virtual ao mesmo tempo sem saber qual modo o software espera.

MP-4200 TH com Ethernet: localizar e configurar o IP

Use esta parte somente se sua unidade tiver placa de rede RJ45 instalada.

1

Conecte a Ethernet

Ligue o cabo RJ45 ao roteador/switch e deixe a impressora ligada.

2

Abra o Bematech User Software

Selecione comunicação Ethernet e use a função de procurar/localizar impressoras na rede.

⬇️ Baixar User Software

3

Confira ou defina o IP

Selecione a impressora encontrada e configure um endereço compatível com a rede. Para PDV, prefira um IP estável para evitar que a porta do Windows pare de apontar para o equipamento.

4

Teste a comunicação

No Windows, use ping 192.168.x.x substituindo pelo IP da impressora. Se responder, o computador alcança o equipamento na rede.

5

Instale o spooler usando o IP

No instalador Bematech, escolha a MP-4200 TH e a opção de rede/TCP-IP quando disponível, informando o endereço configurado. Finalize com página de teste.

Autoteste sem computador

Serve para separar problema físico da impressora de problema de Windows, driver ou rede.

1

Desligue

Deixe bobina instalada e tampa fechada.

2

Segure AVANÇO/FEED e ligue

Mantenha o botão de avanço pressionado ao ligar até o equipamento iniciar o menu/autoteste.

3

Confira a impressão

Se o autoteste imprime normalmente, concentre o diagnóstico em driver, porta, IP ou software.

Problemas comuns

Comece pelo sintoma.

Instalei o driver, mas não imprime

Confirme se o sistema está enviando para a mesma impressora/porta criada pelo spooler. Se o software trabalha por COM, não basta criar somente a impressora do Windows.

A USB criou uma porta COM

Isso pode ser normal quando o driver USB virtual está sendo usado. Confira no Gerenciador de Dispositivos qual número COM foi atribuído e configure o sistema com o mesmo número.

O cupom é cortado antes do final

Se o problema acontece somente em cupons longos, revise o tamanho/formulário do papel no spooler do Windows. Instalações antigas da MP-4200 TH podem precisar de um formulário personalizado.

A impressora de rede parou depois de reiniciar o roteador

Descubra o IP atual no User Software. Se o endereço mudou por DHCP, ajuste a porta do Windows e depois reserve ou configure um IP estável.

Caracteres ou acentos saem errados

Em comunicação direta ESC/POS/Bematech, verifique a página de código configurada no software e na impressora. Não tente corrigir somente trocando fonte do Windows.

Tenho uma MP-4200 HS. Posso usar este driver?

Não trate HS como TH. A MP-4200 HS é uma revisão posterior e a própria documentação independente de drivers orienta usar o driver Elgin correspondente à HS.
