Não confundir com TH ADV ou HS
Resposta rápida: para instalar a MP-4200 TH original como impressora do Windows, o pacote de spooler mais usado neste guia é o Bematech v5.0.0.4. Por ser um modelo legado, valide o funcionamento no seu Windows antes de alterar uma máquina de produção.

Windows 11: a MP-4200 TH funciona?

Como a MP-4200 TH original é uma plataforma antiga, não é seguro prometer compatibilidade universal com instalações atuais.

Em Windows 11, trate o spooler como driver legado a validar. Instale em um computador de teste, confirme que a fila é criada e faça uma página de teste antes de configurar o PDV. Se o Windows imprime, mas o sistema não, o problema passa a ser seleção da fila, COM, IP ou modo de integração.

Veja o guia de instalação de impressoras térmicas no Windows 11.

Como instalar a MP-4200 TH por USB

Use este fluxo para uma instalação de spooler convencional.

1

Confirme o modelo

Veja a etiqueta e confirme MP-4200 TH, sem ADV e sem HS.

2

Baixe e extraia o spooler

Use o pacote v5.0.0.4 e extraia todos os arquivos antes de executar.

3

Execute como administrador

Selecione a MP-4200 TH e a conexão USB.

4

Conecte direto ao PC

Evite hub USB durante o primeiro teste.

5

Imprima uma página de teste

Em Impressoras e scanners, abra as propriedades da MP-4200 TH e confirme a impressão.

USB como COM virtual

Alguns sistemas de automação não imprimem pelo spooler e esperam comunicação direta por porta serial.

Nesse cenário, instale o driver USB/COM e confira no Gerenciador de Dispositivos → Portas (COM e LPT) qual número foi criado. Configure exatamente essa COM no sistema. Não misture impressão por spooler e comunicação COM sem saber qual modo o software exige.

Problemas comuns da MP-4200 TH

Diagnóstico por sintoma.

A MP-4200 aparece offline

Em USB, confira cabo e porta. Em Ethernet, confirme se o IP mudou. Também verifique se a fila correta está selecionada.

Windows não reconhece a USB

Teste outra porta/cabo, evite hub e confirme se o modo usado é spooler ou COM virtual.

A página de teste funciona, mas o PDV não imprime

O driver está funcional. Revise no sistema a fila, COM, IP e o modo de integração.

Tenho uma MP-4200 TH ADV ou HS

Use o tutorial da revisão correta. Não instale o pacote da TH original apenas porque o nome é parecido.

O papel sai em branco

Confirme o lado térmico da bobina. Se o autoteste também sair em branco, investigue mídia/cabeça e hardware.

Impressora térmica não imprime · offline · USB não reconhece.
