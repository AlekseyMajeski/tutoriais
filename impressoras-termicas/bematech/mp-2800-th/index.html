Instalação principal no Windows

Para o cenário mais comum, tente primeiro o spooler exclusivo da MP-2800.

1

Confirme a etiqueta

Verifique se o modelo é realmente MP-2800 TH.

2

Baixe e extraia o v1.3

Extraia DriverSpoolerExclusivoMP-2800_V1.3.zip para uma pasta local.

3

Execute como administrador

Abra o instalador contido no pacote e avance pelas opções disponíveis.

4

Selecione a porta correta

Para uma conexão USB comum, deixe a impressora ligada/conectada quando necessário. Se o sistema utiliza COM virtual, veja a seção seguinte.

5

Teste pelo Windows

Abra as propriedades da MP-2800 e faça uma página de teste antes de configurar o PDV.

USB como COM virtual

Use somente se o software de automação esperar uma porta COM.

1

Instale o USB COM

Execute o pacote oficial legado disponibilizado no repositório.

2

Veja o número da COM

No Gerenciador de Dispositivos, abra Portas (COM e LPT) e anote a porta criada.

3

Configure o sistema

Informe a mesma COM no software. Não confunda impressão pelo spooler com comunicação direta por COM.

Problemas comuns

O instalador antigo não reconhece a impressora

Confirme o modelo, tente outra porta/cabo USB e execute o instalador como administrador.

Apareceu uma porta COM, mas não imprime no Windows

COM virtual e spooler são modos diferentes. Configure o modo de comunicação que o software realmente usa.

A página de teste funciona, mas o PDV não imprime

O driver e a conexão básica estão funcionando. Revise no PDV o modo de comunicação, a impressora escolhida e a porta configurada.

Posso instalar driver da MP-4200?

Não use driver de outro modelo como primeira opção. O repositório mantém um spooler exclusivo da MP-2800.
