Instalar no Windows pelo spooler

Use este fluxo se o seu sistema imprime pela fila normal do Windows.

1

Confirme que é ADV

Veja etiqueta, documentação ou versão do equipamento antes de usar recursos específicos de firmware.

2

Escolha x64 ou x86

Em praticamente todo Windows 10/11 atual, use x64. Use x86 somente se o Windows realmente for 32 bits.

3

Execute como administrador

Instale o Spooler Bematech 5.0.0.4 e selecione a MP-4200 correspondente.

4

Selecione a porta correta

Para USB, conecte diretamente ao computador. Para rede, associe a fila ao IP configurado na impressora.

5

Faça uma página de teste

Abra Impressoras e scanners → MP-4200 → Propriedades da impressora e mande imprimir.

Spooler ou USBCOM?

Se o sistema imprime pela fila do Windows, use o Spooler. Se o aplicativo legado exige algo como COM3/COM4, use o Bematech USBCOM e configure no sistema exatamente a COM criada.

Ethernet e configuração de IP

As unidades ADV com interface Ethernet podem ser utilizadas diretamente na rede.

1

Conecte ao roteador ou switch

Use cabo de rede e mantenha o computador na mesma rede lógica.

2

Identifique o IP

Use o Bematech User Software, as informações impressas pela própria unidade ou a configuração já registrada no ambiente.

3

Teste comunicação

No Windows, execute ping ENDEREÇO-IP. Responder ao ping confirma a camada IP, mas não garante que a fila esteja configurada corretamente.

4

Mantenha o endereço estável

Em PDV, use IP fixo ou reserva DHCP. Depois configure a porta TCP/IP da fila de impressão.

Problemas comuns da MP-4200 TH ADV

Qual driver devo usar no Windows 11?

Para impressão normal via spooler, use o Bematech Spooler 5.0.0.4 x64 em Windows 64-bit. Se o sistema exige porta COM, use também o Bematech USBCOM.

O instalador mostra MP-4200 TH e não “ADV” em todos os lugares

É esperado. A Elgin organiza drivers e manuais da ADV dentro da pasta MP-4200 TH; o firmware, porém, tem diretório próprio MP-4200TH_ADV.

A COM criada não aparece no sistema

Abra o Gerenciador de Dispositivos, confirme o número da COM virtual, reinicie o aplicativo e configure exatamente essa porta no sistema.

A impressão de rede parou

Confira se o IP da impressora mudou e se a porta TCP/IP ainda aponta para o endereço correto. Depois configure IP fixo ou reserva DHCP.

Devo atualizar o firmware 04.07?

Somente se houver necessidade concreta ou orientação técnica. Não atualize firmware de forma preventiva em uma unidade funcionando normalmente.
