Instalação por USB no Windows

Esse é o caminho mais simples para a maioria dos PDVs.

1

Confira se é HS

Veja a etiqueta. Se for TH ou TH ADV, volte e use o tutorial correspondente.

2

Baixe o driver v1.8.0

Extraia completamente o ZIP para uma pasta local.

3

Execute como administrador

Abra o instalador e avance pelas opções disponíveis.

4

Escolha USB

Conecte a impressora diretamente ao computador e associe a porta USB quando solicitado.

5

Teste no Windows

Abra Impressoras e scanners → MP-4200 HS → Propriedades da impressora e imprima uma página de teste.

Ethernet: configurar IP e porta de rede

A MP-4200 HS atual é comercializada com Ethernet, além de USB e Serial.

1

Conecte a Ethernet

Ligue a impressora ao switch/roteador e deixe o PC na mesma rede.

2

Localize o endereço

Use as informações de status/autoteste da interface ou o ELGIN Utility para descobrir/configurar o IP.

3

Defina endereço estável

Para PDV, use IP fixo ou reserva DHCP. Se o IP mudar, a fila de impressão pode continuar apontando para o endereço antigo.

4

Teste a rede

Faça ping ENDEREÇO-IP. Resposta ao ping confirma conectividade básica, não a configuração da porta de impressão.

5

Associe o driver ao IP

Configure a porta TCP/IP usada pela fila da MP-4200 HS e faça uma página de teste.

Conexão Serial

Use quando o equipamento estiver fisicamente ligado por Serial e o sistema trabalhar nesse modo.

Veja no Windows qual porta COM está disponível e confirme no software os parâmetros de comunicação exigidos. Não misture configuração Serial com fila USB/TCP-IP: primeiro identifique como o PDV envia a impressão e configure apenas esse caminho.

🐧 Linux

Baixe o driver Linux v1.2.5, extraia o pacote e siga os arquivos de instalação incluídos. Em servidores ou caixas de produção, valide primeiro em uma máquina de teste.

🧾 Autoteste

Antes de reinstalar driver, faça o autoteste previsto para a impressora. Se ela imprime sozinha, concentre o diagnóstico no cabo, IP, porta, driver ou software.

Problemas comuns

Instalei driver da MP-4200 TH e a HS não funciona

Remova a confusão de modelos e use o pacote específico da HS. O repositório técnico mantém diretórios e drivers separados para TH e HS.

A USB funciona no Windows, mas o PDV não imprime

Faça a página de teste. Se funcionar, revise no PDV a impressora selecionada e o modo de comunicação configurado.

A impressora Ethernet ficou offline

Confira o IP atual. Se mudou via DHCP, atualize a porta e depois configure um endereço estável.

Linux: posso usar o instalador de Windows?

Não. Use o pacote Linux v1.2.5 mantido separadamente pela Elgin/Bematech.

Preciso do ELGIN Utility para instalar?

Não necessariamente para uma instalação USB simples. O utilitário é mais útil para configuração, diagnóstico e cenários de rede.
