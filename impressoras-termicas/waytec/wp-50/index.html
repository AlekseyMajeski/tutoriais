Instalação USB

1

Baixe o driver

Use o pacote Drivers_WP-50.zip hospedado pela própria Waytec.

2

Instale o pacote

Extraia o ZIP, execute o instalador correspondente ao sistema e siga o assistente. Não use pacote da WP-100.

3

Conecte por USB

O manual oficial documenta USB como interface de comunicação. Ligue a impressora e aguarde a detecção pelo sistema.

4

Faça um teste

Use o Printer Tools WP50 ou a página de teste do sistema antes de configurar o PDV.

Problemas comuns

WP-50 não aparece no computador

Troque cabo e porta USB, religue a impressora e confira o Gerenciador de Dispositivos. Depois reinstale o pacote oficial.

Instalou, mas não imprime

Confirme a porta da fila e teste primeiro pelo Windows/Printer Tools. Só depois selecione a impressora no sistema de PDV.

Posso usar driver genérico ESC/POS?

A impressora é compatível com ESC/POS, mas para a instalação do sistema prefira o pacote específico mantido pela Waytec.

É impressora de rede?

O manual oficial consultado documenta USB como interface da WP-50. Não configure IP/Ethernet sem confirmar uma revisão física diferente na etiqueta ou documentação do equipamento.
