Instalação

1

Baixe o pacote

No Windows use o WayTec Printer Driver Setup V7.17; no Linux use o pacote WP-100_Linux.

2

Instale antes do PDV

Execute o instalador, escolha o modelo/porta apresentados pelo pacote e conclua a instalação.

3

Teste a comunicação

Use o WP100 Printer Test oficial ou uma página de teste do sistema operacional.

4

Configure o sistema

Somente depois do teste básico funcionar selecione a WP-100 no seu PDV.

Problemas comuns

Instalador não encontra a impressora

Troque a porta USB/cabo, religue a impressora e confira o Gerenciador de Dispositivos antes de reinstalar.

Driver instalado, mas não imprime

Confira a porta associada à fila e faça o teste pelo Windows ou Printer Test antes do PDV.

Preciso do Linux

Use somente o pacote WP-100_Linux mantido no diretório oficial Waytec; evite drivers genéricos de sites de download.

Qual arquivo devo usar?

O diretório oficial contém manual, Linux, Printer Test e o instalador Windows V7.17. Não misture arquivos de WP-50 ou outros modelos.
