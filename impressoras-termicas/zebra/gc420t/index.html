Zebra GC420t

A GC420t é uma impressora desktop de transferência térmica. A Zebra orienta instalar o Zebra Setup Utilities, que inclui o Windows Printer Driver v5, e aponta a série ZD200 como substituta.

Qual driver usar?

Use o Zebra Setup Utilities com Windows Printer Driver v5, conforme orientação oficial.

A GC420t é atual?

Não. A Zebra descontinuou o modelo e aponta a série ZD200 como substituta.
