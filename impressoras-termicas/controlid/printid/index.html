Instalação principal por USB

Para uso normal no Windows, o caminho é baixar o driver, instalar e testar.

1

Confirme o modelo

Veja se a etiqueta corresponde à Print iD. A Print iD Touch é outro produto e possui recursos adicionais.

2

Baixe o driver

Use o botão acima para baixar DriverPrintiD_Windows.zip.

3

Extraia o ZIP

Extraia todos os arquivos para uma pasta local.

4

Execute e avance

Abra o instalador, de preferência como administrador, e siga as opções indicadas até finalizar. Conecte a porta USB B da impressora ao computador quando necessário.

5

Faça uma página de teste

No Windows, abra Impressoras e scanners → Print iD → Propriedades da impressora e faça uma impressão de teste.

Ethernet: localizar e configurar o IP

A Print iD possui interface web própria e utilitário oficial de rede.

1

Conecte o cabo de rede

Ligue a porta Ethernet da Print iD ao roteador ou switch e mantenha o computador na mesma rede.

2

Localize a impressora

Use o Control iD Network Explorer para localizar a Print iD e verificar o endereço configurado.

⬇️ Baixar utilitário de rede

3

Se estiver no padrão de fábrica

O guia rápido da Control iD informa o IP padrão 192.168.0.128. Na mesma faixa de rede, abra http://192.168.0.128 no navegador. O guia indica usuário e senha admin.

Não force esse IP se a rede estiver em outra faixa. Use o utilitário de rede ou ajuste temporariamente o computador apenas se souber o que está fazendo.
4

Configure um IP estável

Defina um endereço compatível com a rede do estabelecimento. Para PDV, prefira um IP fixo ou reserva DHCP para evitar que a impressora mude de endereço.

5

Teste a comunicação

Use ping ENDEREÇO-IP no Prompt de Comando e depois faça uma impressão de teste pelo driver/porta TCP-IP.

Restaurar o IP de fábrica

Segundo o guia rápido: desligue a Print iD, mantenha POWER + PAPER FEED pressionados simultaneamente por cerca de 15 segundos ou até ouvir cinco bipes, aguarde o LED INFO apagar e então o IP volta para 192.168.0.128.

Wi‑Fi e Bluetooth

Não são interfaces internas padrão da Print iD.

A Control iD informa que Wi‑Fi e Bluetooth funcionam por módulos USB externos conectados à porta USB Host tipo A. Portanto, não procure configuração sem fio se sua unidade não tiver o módulo correspondente instalado.

Autoteste sem computador

O próprio equipamento imprime um ticket de diagnóstico.

1

Desligue a Print iD

Deixe papel instalado e a tampa fechada.

2

Segure POWER ao ligar

Mantenha POWER pressionado até ouvir 3 bipes e solte o botão.

3

Aguarde o ticket

O autoteste será impresso após alguns segundos. Se sair corretamente, mecanismo e impressão básica estão funcionando.

Problemas comuns

Comece pelo sintoma.

O Windows não encontra a Print iD USB

Confirme o cabo USB A-B, teste outra porta do computador, evite hubs e reinstale o driver oficial.

Não consigo abrir 192.168.0.128

Esse é o padrão de fábrica, mas a impressora pode já ter outro IP. Use o Network Explorer para localizar o endereço atual. Também confirme se o computador está na mesma rede/faixa.

O IP mudou e o PDV parou de imprimir

Localize o endereço atual, defina um IP estável e atualize a porta TCP/IP usada pelo Windows ou pelo sistema.

Quero usar Wi‑Fi, mas não aparece opção

A Print iD precisa do módulo Wi‑Fi USB externo específico. A porta USB Host sozinha não cria Wi‑Fi.

O autoteste funciona, mas o sistema não imprime

Se o autoteste funciona, revise driver, porta USB/IP e a impressora selecionada no PDV.
